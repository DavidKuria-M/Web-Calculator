# Web Calculator

A modern, responsive web calculator built with **HTML, CSS, and JavaScript**. It features a clean user interface and functional calculator operations, providing a simple and intuitive experience across different screen sizes.

## Features

- **Basic Arithmetic:** Perform addition, subtraction, multiplication, and division.
- **Percentage Calculations:** Calculate percentages.
- **Clear Function:** Reset the calculator display and start a new calculation.
- **Positive/Negative Toggle:** Switch between positive and negative numbers.
- **Decimal Support:** Perform calculations involving decimal numbers.
- **Interactive UI:** Responsive buttons and a clear display for a smooth user experience.
- **Responsive Design:** Designed to work across different screen sizes.

## Technologies Used

- **HTML5** – Structures the calculator interface.
- **CSS3** – Styles the layout, buttons, and display.
- **JavaScript** – Implements the calculator logic and interactive functionality.

## Getting Started

### Prerequisites

A modern web browser such as Google Chrome, Firefox, or Microsoft Edge.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/DavidKuria-M/Web-Calculator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Web-Calculator
   ```

3. Open `index.html` in your browser to use the calculator.
